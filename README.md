# Mediterranean Forest Mortality Risk Framework

**Author:** Dr. Filippos Eliades  
**Institution:** Cyprus University of Technology  
**Year:** 2026  

## What this framework does

A remote sensing framework for identifying drought-driven tree mortality risk in Mediterranean forests. Built on confirmed 100% mortality sites and validated when new mortality in 2025 fell precisely inside the pre-mapped high-risk zones.

## Variables used

- Satellite canopy indicators: NDVI, NBR
- Drought indices: SPI, SPEI, PDSI
- Topographic variables: slope, aspect, TPI, curvature
- Solar exposure
- Lithology

## Platform

Google Earth Engine (GEE)
